📲 Hướng Dẫn Cài Đặt Vào Điện Thoại

Ứng dụng hỗ trợ cài trực tiếp làm App di động độc lập (PWA hoặc APK Android), hoạt động hoàn hảo ngoại tuyến.

🤖 Cách 1: Trên điện thoại Android (Chrome / Cốc Cốc) 1. Mở trang web này trên trình duyệt Chrome trên điện thoại.
2. Bấm vào nút "Cài đặt ngay" trên banner màu xanh, hoặc bấm vào menu 3 chấm (⋮) ở góc trên bên phải màn hình.
3. Chọn dòng "Cài đặt ứng dụng" (hoặc "Thêm vào màn hình chính").
🍎 Cách 2: Trên iPhone / iPad (Trình duyệt Safari) 1. Mở trang web bằng trình duyệt Safari.
2. Bấm vào nút Chia sẻ (biểu tượng mũi tên hướng lên 📤) ở thanh công cụ dưới đáy màn hình.
3. Cuộn xuống và chọn "Thêm vào MH chính" (Add to Home Screen ➕).
📦 Cách 3: Đóng gói thành file APK Android cài trực tiếp Chạy 3 lệnh sau trong thư mục dự án VS Code: 
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap add android
npx cap open android
Trong Android Studio: Chọn Build → Build APK để lấy file .apk cài vào điện thoại!
